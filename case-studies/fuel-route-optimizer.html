Django / Route optimization

Choosing fuel stops by cost and vehicle range

Plan fuel stops along a route using station prices and locations while accounting for vehicle range.

Django REST API SQLite Routing

01 / The challenge

A route needs feasible fuel stops

A route planner must consider more than the distance between two locations. Fuel prices vary by station, and the vehicle's range limits which stops are reachable.

02 / The investigation

Price and range have to be evaluated together

The optimizer uses station coordinates and fuel prices along with route geometry. Its documented model assumes a 500-mile tank range and 10 miles per gallon, making those vehicle assumptions explicit inputs to stop selection.

03 / The implementation

Import station data and expose route planning through an API

A Django backend stores fuel-station data in SQLite and can import records from CSV. The route-fuel endpoint returns route geometry, recommended stops, and estimated cost and fuel totals. Identical requests are cached for one hour.

04 / The outcome

A route plan with explainable stop data

The API response includes the route, selected station details, refill amounts, and estimated totals, so the plan can be inspected rather than returned as a single opaque recommendation. Prices reflect the imported station data, not a live feed.
