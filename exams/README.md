# زاد الفقه — صفحة اختبارات ثابتة

## الملفات
- `index.html`: هيكل الصفحة.
- `styles.css`: التصميم والحركات والتجاوب مع الهاتف.
- `app.js`: منطق الاختبارات والتصحيح والنتائج والمراجعة.
- `questions.json`: بنك الأسئلة المنظم.

## التشغيل محلياً
لا تفتح `index.html` مباشرة عبر `file://` لأن المتصفح قد يمنع تحميل JSON. شغّل خادماً محلياً بسيطاً من هذا المجلد:
`python -m http.server 8000`
ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages
ارفع الملفات الأربعة إلى جذر المستودع (أو المجلد المحدد في إعدادات Pages)، ثم فعّل Pages من Settings → Pages واختر الفرع والمجلد. لا يحتاج المشروع إلى Node أو قاعدة بيانات أو build.

## إضافة سؤال
أضف كائناً جديداً إلى `questions` في `questions.json`:
```json
{
  "id": "lesson-1-q11",
  "lessonId": "lesson-1",
  "type": "mcq",
  "prompt": "نص السؤال؟",
  "options": [
    {"id": "o1", "text": "الاختيار الأول"},
    {"id": "o2", "text": "الاختيار الثاني"}
  ],
  "correctOptionId": "o2",
  "explanation": "",
  "tags": []
}
```
استخدم `type: "tf"` لأسئلة الصح والخطأ، واجعل خياراتها `صح` ثم `خطأ`. يجب أن يكون `lessonId` مطابقاً لمعرف درس موجود في `lessons`. الاختبار العشوائي يقرأ كل الأسئلة تلقائياً ويختار العدد المطلوب دون تكرار.
